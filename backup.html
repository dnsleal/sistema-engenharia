Backup dos dados

O plano gratuito do Supabase não guarda cópia que você possa baixar. Baixe a sua aqui, de preferência todo mês.

Guardar no Google Drive

  1. Gere o backup acima: os arquivos vão para a pasta de downloads.
  2. Abra o Drive (drive.google.com ou o app no celular) e arraste os arquivos para uma pasta Backup Sistema.
  3. Guarde pelo menos os 3 últimos meses. O nome de cada arquivo já leva a data.
